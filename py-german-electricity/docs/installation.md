# Installation

## Stable release

To install German Electricity Modeling 2014-2020, run this command in your terminal:

```sh
uv add py-german-electricity
```

Or if you prefer to use `pip`:

```sh
pip install py-german-electricity
```

## From source

The source files for German Electricity Modeling 2014-2020 can be downloaded from the [Github repo](https://github.com/Matshiselan/py_german_electricity).

You can either clone the public repository:

```sh
git clone https://github.com/Matshiselan/py_german_electricity
```

Or download the [tarball](https://github.com/Matshiselan/py_german_electricity/tarball/main):

```sh
curl -OJL https://github.com/Matshiselan/py_german_electricity/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd py_german_electricity
uv sync
```
